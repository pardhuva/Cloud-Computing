//Inmemory data grid 
    While grid computing is often used for large-scale distributed projects, it can also be applied locally within a single organization. 
    For example, a company can set up a cluster of connected computers that work together on a task — this is a form of local grid computing.
    
    A special type of local grid is the In-Memory Data Grid (IMDG). In an IMDG, all the connected computers store the data in their memory and work together using coordination software.
     Because the data is kept in memory on all nodes, access is extremely fast, making IMDGs ideal for tasks that require very high speed (throughput) and low delay (latency).
   
   . Local Grid = small-scale grid within one organization
   . IMDG = data stored in memory across all nodes → very fast access
   . Coordination software ensures nodes work together and stay synchronized
   . Best for tasks needing high speed and low latency
   . Local grid computing, especially with IMDGs, connects a cluster of computers to share in-memory data and work together efficiently, giving fast access and high-speed processing for demanding tasks.

    Local Grid: Data may be fully replicated (all nodes have all data).
    Global Grid: Data is distributed (each node has part of the data).

    Local grids sacrifice  memory for speed (IMDG).
    Global grids sacrifice  speed for scalability (distributed data storage).

   . high throughput - The number of tasks or instructions completed per unit of time.
                        More computations are done per second.(as many nodes are working together)
   . low latency -  The time delay between requesting data and receiving it.
                    Short waiting time to access data for computation.(as data is stored in memory of all nodes)


//Types of grids 
 1. Computational grids : 
     A computational grid is a network of high-performance computers (servers) connected to work together to solve large-scale computational problems.
     Designed for heavy computational tasks like simulations, scientific calculations, or complex modeling.
     Each server contributes its processing power to the grid.
    ex: Weather forecasting models using multiple supercomputers to process massive computations simultaneously.
  
  2. Scavenging Grids :
      A scavenging grid uses a network of regular desktop computers to perform computing tasks by utilizing idle CPU cycles.
      Uses “spare” computing power of desktops when they are not busy.

  3. Data Grids :
      A data grid is a distributed system that manages, accesses, modifies, and transfers large volumes of data across multiple locations.
      Focused on storage and efficient data sharing rather than computation.
      Ensures reliable access to huge datasets for processing and analysis.
      ex: Scientific data repositories where multiple research labs access and process massive datasets simultaneously.

//Utility computing 
   . Focus: Treats computing as a measured service—you pay for CPU, storage, or network usage like a utility.
   . Scope: Primarily about the billing model and resource usage.
   . Example: Paying for compute hours or storage without owning hardware.

Utility computing makes computing flexible, cost-efficient, and scalable, just like electricity—you consume and pay according to your need.
